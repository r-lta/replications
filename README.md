# replications

Re-implementations of papers I want to understand properly. One folder per paper, named `author_year`. Each has the notebook that trains/evaluates the model; some have a README noting what was replicated, what deviates, and how the result compares.

Longer write-ups, when I make them, are on [r-lta.github.io](https://r-lta.github.io/replications.html).
